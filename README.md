# Segbench

Download the KITTI [Semantic Segmentation Evaluation](https://www.cvlibs.net/datasets/kitti/eval_semseg.php?benchmark=semantics2015) dataset. Move the extracted `data_semantics` folder into the repository root.

```text
segbench/
├── data_semantics/
│   ├── training/
│   └── testing/
└── ...
```
